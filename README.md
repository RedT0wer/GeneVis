# GeneVis — Мобильный визуализатор генов и мутаций

**GeneVis** — это прогрессивное веб-приложение (PWA) для интерактивной визуализации структуры генов, моделирования точечных мутаций, вставок и удалений, а также анализа их влияния на белковые домены. Приложение оптимизировано для мобильных устройств и работает полностью на стороне клиента.

## Основные возможности

### Построение гена
- **Загрузка данных:** Поддержка Ensembl REST API
- **Структурный анализ:** Автоматическое определение экзонов, 5'/3' UTR-областей и кодирующей последовательности (CDS).
- **Белковая архитектура:** Загрузка доменов из UniProt с выравниванием по транслированной последовательности CDS.
- **Трансляция:** Встроенная таблица генетического кода с поддержкой стоп-кодонов.

### Моделирование мутаций
- **Поиск (Find):** Навигация к нуклеотиду/аминокислоте с отображением контекста (экзон, домен, заряд).
- **Замена (Substitution):** Замена одного нуклеотида с мгновенным пересчетом кодона и аминокислоты.
- **Вставка (Insertion):** Вставка произвольной последовательности с учетом рамки считывания.
- **Удаление (Deletion):** Удаление диапазона нуклеотидов с корректным сдвигом координат.

### Визуализация и UX
- **Canvas-рендеринг:** Высокопроизводительная отрисовка последовательностей через HTML5 Canvas.
- **Интерактивность:** Клик по любому символу открывает контекстное меню с биоинформатическими свойствами и навигацией.
- **Подсветка изменений:** Цветовое кодирование мутировавших регионов, границ делеций и стоп-кодонов.
- **Адаптивность:** Интерфейс спроектирован специально для сенсорных экранов.
- **Офлайн-режим:** Service Worker и IndexedDB кэшируют запросы к API на 7 дней.

## Биологическая модель

### Объектная модель
- **Gene:** Корневой объект, связывающий `BaseSequence` и `Protein`.
- **BaseSequence:** Содержит `full_sequence`, массив `Exon`, объекты `UTR` (5' и 3').
- **Exon:** Координаты в cDNA (0-based), длина, номер.
- **Protein:** Аминокислотная последовательность + массив `ProteinDomain`.
- **ProteinDomain:** Выровненный по транслированной CDS домен из UniProt.

### Особенности обработки мутаций
1.  **Сброс состояния:** Каждая новая мутация применяется к *оригинальному* гену (`originalGene`). Цепочки мутаций не накапливаются.
2.  **Стоп-кодоны:** При появлении преждевременного стоп-кодона (`*`) все последующие экзоны и домены скрываются из UI.
3.  **Координаты:** Все внутренние расчеты ведутся в 0-based координатах относительно полной последовательности (включая UTR). Пользовательский ввод — в 1-based CDS-координатах.
4.  **Домены:** После мутации доменная структура перестраивается: домены до точки мутации сохраняются, затронутый домен помечается как `(mutated)` и обрезается по новой длине белка, последующие домены удаляются.

## Технические детали

### Кэширование
- **IndexedDB:** Ответы API хранятся с TTL = 7 дней. Ключи формируются по паттерну `{source}_{type}_{id}`.
- **Service Worker:** Стратегия Cache-First для статики. Версия кэша `genevis-v1`.

### Производительность
- **DOM:** Карточки создаются через `DocumentFragment` и вставляются одним batch-операцией.
- **Canvas:** Используется полифил `roundRect`. Размеры canvas задаются явно через JS для предотвращения размытия на HiDPI.
- **Делегирование:** Обработчики кликов навешиваются на контейнеры, а не на каждую карточку.
- **Бинарный поиск:** Поиск экзона/домена по позиции выполняется за O(log N).

### Состояние (State Management)
Глобальный стейт (`core/state.js`) содержит:
- `geneDataForUI` — текущее представление (может быть мутированным)
- `originGeneDataForUI` — эталонное представление (для откатов)
- `currentMutation` / `lastMutation` — данные для стратегий подсветки
- `domainColorEnabled` — переключатель расцветки доменов
- `activeContext` — ссылка на открытый элемент контекстного меню

## Запуск

Приложение не требует сборки. Достаточно любого статического HTTP-сервера:

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

> **Важно:** Не открывайте `index.html` напрямую через `file://` — Service Worker и модульные импорты ES6 не будут работать без HTTP-сервера.
